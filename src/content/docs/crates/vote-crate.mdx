The **Vote Crate** is **free** — you earn it by **voting** for the server on voting sites. It's limited to **1 opening**, so make it count! It uses the **roulette** animation.

## How to vote

1. Run the vote command/menu (or check Discord for the voting links).
2. Vote on the available sites.
3. Claim your Vote Crate and open it.

## Drop chances

The Vote Crate has **no Rare tier**, so its rarity pool is only Common 70 + Mythic 5 = 75. Every roll picks a rarity by weight, then a reward inside it:

| Rarity | Chance | Per reward |
| --- | --- | --- |
| Common (10 rewards) | **93.33%** | 9.33% each |
| Mythic (1 reward) | **6.67%** | **6.67%** (Elytra) |

That makes the **Elytra** far more likely here than in the End Crate (6.67% vs 1.25%).
