## Drop chances

Every roll first picks a rarity by weight (**Common 70, Rare 25, Mythic 5**), then picks a reward inside that rarity. With 23 rewards total:

| Rarity | Chance | Per reward |
| --- | --- | --- |
| Common (10 rewards) | 70% | **7.00%** each |
| Rare (8 rewards) | 25% | **3.125%** each |
| Mythic (5 rewards) | 5% | **1.00%** each |
