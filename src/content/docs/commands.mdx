Everything you can type, organized by what it does. Commands are grouped by feature — jump to the section you care about.

## Getting around

| Command | What it does |
| --- | --- |
| `/spawn` | Teleport to spawn |
| `/warp` | View available warps |
| `/warp crate` | Teleport to the crate area |
| `/rtp` or `/wild` | Random teleport to the SMP |
| `/home` | Teleport to your home |
| `/sethome` | Set your home at your current position |
| `/delhome` | Delete your home |
| `/homelist` | List all of your homes |
| `/tpa <player>` | Request to teleport to a player |
| `/tpahere <player>` | Ask a player to teleport to you |
| `/tpaccept` | Accept an incoming teleport request |
| `/tpdeny` | Deny an incoming teleport request |
| `/back` | Teleport back to where you died or last teleported |

Current **warps** are `skydive`, `church`, and `crate` — use `/warp <name>` to jump to them.

## Survival & SMP

| Command | What it does |
| --- | --- |
| `/kit` or `/kits` | Open the kits menu |
| `/claim` | Claim the area you've selected |
| `/unclaim` | Remove a claim |
| `/claim trust <player>` | Give a player access to your claim |
| `/claims` | View your claims |
| `/pvp` | Toggle PvP on/off (off by default) |

## Prison

| Command | What it does |
| --- | --- |
| `/prison` | Open the main prison menu |
| `/prison join` | Join the prison world |
| `/rankup` | Buy the next rank |
| `/ranks` | View the rank ladder |
| `/sell` | Sell your inventory's blocks |
| `/autosell` | Toggle automatic selling while mining |
| `/prestige` | Prestige at max rank |

## Money & economy

| Command | What it does |
| --- | --- |
| `/balance` or `/bal` | Check your Vault money (the $ used for prison ranks) |
| `/ultcoins` | Check your ultcoin balance 🪙 |
| `/shop` or `/ultshop` | Open the spawner shop |
| `/ushop` | Open the ultimate shop |
| `/jobs` or `/job` | Open the jobs menu |
| `/questboard` | Open the quest board |
| `/questshop` | Spend quest points |
| `/baltop` | View the top balances |

## Crates & rewards

| Command | What it does |
| --- | --- |
| `/crate` or `/crates` | Open the crate menu |
| `/crates preview <crate>` | Preview a crate's loot table (left-click a crate NPC does this too) |
| `/crates open <crate>` | Open a crate (right-click a crate NPC does this too) |
| `/vote` | Vote for the server and claim your vote crate key |
| `/vote shop` | Spend Voting Points in the vote shop |
| `/votefree` | Open the vote crate |

## Bank & profiles

| Command | What it does |
| --- | --- |
| `/bank` | Open the bank (deposit / withdraw ultcoins) |
| `/bank deposit <amount>` | Deposit ultcoins into your bank |
| `/bank withdraw <amount>` | Withdraw ultcoins from your bank |
| `/profile` | View your profile card |
| `/profile <player>` | View another player's profile |
| `/baltop` | View the top 10 richest players |
| `/ultsell` | Sell items back (spawners resell for 50%) |

## Pets

| Command | What it does |
| --- | --- |
| `/pet` or `/fpets` | Open your pet menu |
| `/fpets my` | View your owned pets |
| `/fpets equip <pet>` | Equip a pet to follow you |
| `/fpets call` | Call your equipped pet to you |
| `/fpets ride` | Ride your equipped pet |
| `/fpets hat` | Wear your pet on your head |

## Prefixes & chat

| Command | What it does |
| --- | --- |
| `/prefix` | Open the prefix menu |
| `/fsp my` | View your collected prefixes |
| `/fsp unequip` | Remove your equipped prefix |
| `/msg <player> <message>` | Send a private message |

## Teams

| Command | What it does |
| --- | --- |
| `/team` | Open the team menu |
| `/team create <name>` | Create a team |
| `/team invite <player>` | Invite a player to your team |
| `/team join <name>` | Join a team you were invited to |
| `/team leave` | Leave your current team |
