Complete daily quests on the **quest board** to earn **quest points**, which you spend in the [quest shop](/economy/quest-shop/). Questing is powered by **AxQuestBoard**.

## The quest board

- Open with `/questboard` (or `/qb`, `/axquestboard`, `/axqb`).
- The board holds a rotating set of quests — it grows as more players are online:
  - 1 row at 0–4 players, up to **6 rows (27 quests)** at 25+ players.
- Each quest shows your progress, the leaderboard (top 3), and the reward.
- When a quest is completed, a new one appears after a **30-minute cooldown**.

## Example quests

| Quest | Goal | Reward |
| --- | --- | --- |
| Kill 100 creepers | Kill 100 creepers | 3 points + rewards |
| Break 10 ancient debris | Break 10 ancient debris | 5 points |
| Break 7,500 blocks | Break 7,500 blocks | 3 points |
| *(and more — the pool rotates)* | | |

Quests come from a pool with different **chances** to appear (some are rarer than others), and each has a top-3 leaderboard race.

## Rewards

- **Quest points** — the main currency for the [quest shop](/economy/quest-shop/).
- Top finishers also get bonus rewards (items/commands).

## Commands

| Command | What it does |
| --- | --- |
| `/questboard` | Open the quest board |
| `/questshop` | Open the quest shop |
