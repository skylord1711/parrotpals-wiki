Throughout the day, **chat games** start in chat. Be the first to answer correctly to win **1,000 ultcoins 🪙**! Each game gives 60 seconds to answer.

## The games

| Game | How to win | Display |
| --- | --- | --- |
| **Math Wizard** | Solve the equation in chat | Math |
| **Trivia Time** | Answer the trivia question | Trivia |
| **Word Scramble** | Unscramble the word | Word Scramble |
| **Reaction Test** | First to react correctly | Reaction Test |
| **Multiple Choice** | Pick the right option | Multiple Choice |

## Rewards

- **1,000 ultcoins 🪙** per win (paid via the economy).
- Watch for the game announcement, then type your answer in chat.
- You have **60 seconds** before the answer is revealed and the game times out.

## Tips

- Keep chat open while AFK-mining or grinding — free ultcoins!
- Games run automatically and randomly, so timing is everything.
- Pair this with [mob farming](/economy/mob-rewards/) to stack ultcoins fast.
