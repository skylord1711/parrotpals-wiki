title: Prestige
description: Reset your ranks to earn prestige tiers, perks, and cosmetics.

When you reach the top rank (**Zenith**), you can **prestige**. Prestige resets your rank back to Budgie but keeps your money and gives you permanent perks that stack each prestige.

## How prestige works

- **Base cost:** $1,000,000
- **Cost multiplier:** 1.5x per prestige level (each prestige costs more than the last)
- Once you prestige, you start back at **Budgie** and climb again.
- Your in-game tag shows `[P{level}]` (e.g. `[P3]`).

## Prestige rewards (every prestige)

| Reward | Details |
| --- | --- |
| **Multiplier bonus** | +10% income per prestige (stacks) |
| **Tokens** | 10,000 tokens |
| **Rare crate key** | 1 Rare prison crate key |
| **Broadcast** | Your prestige is announced to the server |

## Unlocks at specific prestige levels

| Prestige | Unlock |
| --- | --- |
| 1 | Autosell + Golden pickaxe skin |
| 2 | Iron skin, Lucky Miner upgrade, Prestige II mine |
| 3 | Explosive upgrade, Flame block effect |
| 5 | Netherite skin, Laser upgrade, Phoenix pet, Prestige V+ mine |
| 7 | Cloud trail, Green chat color, Boss Lure upgrade |
| 10 | Dragon Breath trail, Thunder join effect, Dragon pet, Light Purple chat |
| 15 | Red chat color, Totem block effect |
| 20 | Heart Explosion join effect |
| 25 | Soul block effect |

Pets unlocked by prestige are cosmetic companions — see [Pets](/progression/pets/).

## Prestige commands

| Command | What it does |
| --- | --- |
| `/prestige` | Prestige when at max rank |
| `/prestiges` | View your prestige level and perks |
