There are **two active kits** on Parrot Pals. Open the kits menu with `/kit` or `/kits`.

## Starter Kit ✦

Every player can claim this **once** — it's your first kit on the server. It gives you the essentials to survive and get started.

| Iron Sword (Sharpness I, Unbreaking I) | 1 |
| Iron Pickaxe (Efficiency I) | 1 |

| Iron Shovel | 1 |
| Cooked Beef | 32 |
| Oak Log | 8 |

| Leather Chestplate | 1 |
| Leather Leggings | 1 |
| Leather Boots | 1 |
| Parrot Spawn Egg | 1 |
| Crafting Table | 1 |
| Furnace | 1 |

## Premium Kit 💰

A paid kit that gives a money boost.

- **Cost:** $5,000 (Vault)
- **Cooldown:** 24 hours

| Item | Amount |
| --- | --- |
| Diamond Block | 16 |
| Emerald Block | 16 |
| Netherite Ingot | 4 |

## Disabled / inactive kits

The server config also contains disabled example kits that are **not currently claimable** (MVP, Daily, Builder, PvP, VIP, Weekly). They're kept in the config as future options — if they get enabled, this page will be updated.

## Notes

- Kits are stored per player — claim your Starter Kit immediately after joining.
- The Premium Kit pays for itself with the Netherite Ingots (4 × $1,200 = $4,800) plus diamond and emerald blocks.
